# Dayshift Coffee — site templates

Four self-contained pages. Each is one HTML file: no build step, no dependencies
beyond Google Fonts. Open any of them in a browser, or upload as-is to any host.

All names, prices, addresses and the brand "Dayshift Coffee / 412 Kettle Street"
are placeholders — swap them for the real shop. Every colour in the artwork is a
CSS token at the top of the file, so a rebrand is a short edit.

| File | What it is | Published |
|---|---|---|
| `morning-rush.html` | Looping illustrated scene — four regulars order, a barista makes it, a live cups counter on the chalkboard. Colour cartoon, speech balloons, confetti, WebGL sky in the window. | https://claude.ai/artifact/E4gBydfsG7RCDeM172biib |
| `crema.html` | WebGL crema hero, scroll-scrubbed espresso extraction (cup fills, yield 0→41 g over 27 s). Quiet and editorial. | https://claude.ai/artifact/7b9MDugPce3vq9pRVL6JhY |
| `morning-regular.html` | Cinematic loop — a man walks in, orders, leaves. Backlit silhouettes over a haze shader, film subtitles, slow camera push. | https://claude.ai/artifact/UBc6ZsbMN35Xv619wisbKt |
| `dayshift-coffee.html` | The full shop site: dial-in menu cards and a live wedding-cart quote calculator (guests / hours / miles / package / add-ons). | https://claude.ai/artifact/B9xbATXoTjX9Uo2dcqdDBE |

The artifact links are private — nobody else can open them until they are shared
from the page's Share menu. The files here do not depend on those links.
